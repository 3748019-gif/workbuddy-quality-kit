# 验证安装和交付

1. 在准备目录运行安装手册列出的四组自检，核对各组返回码和通过数，并用 install_skill.py verify 检查已安装文件。程序检查覆盖文件结构、规则处理和安装行为。
2. 在新建的 WorkBuddy 任务中，让它从已安装目录读取 SKILL.md，再按任务读取对应参考，以确认客户端能发现并调用技能。
3. 用虚构材料试做一份可编辑文件。对照来源核实数字、范围和状态，另存副本并检查原件。制作演示文稿时，用实际演示软件打开，核对文字、图片、重点和阅读顺序。
4. 遇到同名不同内容的技能，保留现有目录并报告冲突。回退前按安装收据检查文件是否经过人工修改。

安装指令、检查命令和预期结果见[安装手册](INSTALL.md)。
