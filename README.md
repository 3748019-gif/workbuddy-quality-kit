# WorkBuddy Quality Kit 5.1

这个工具帮助 WorkBuddy 减少漏读资料、漏做要求、误改原件和任务中断后接不上进度的问题。这次重点加强交付前的内容检查：核对数字与范围、保留例外和未知、检查前后说法是否一致，并在发现错误后修改实际成果、重新核对。检查同时覆盖表格、文字说明和最后给用户的回复。文件交付还可选择开启一次自动纠正，减少文件已经检查完、最后回复却又说错的情况。
复杂任务会按流程另开一次检查，只看原要求、资料和实际成果；需要直接回答的内容也一起核对。这个检查仍可能出错，不能当作正确保证。
检查先从原资料形成判断，再看成品，减少被原答案带偏；没有实质错误就保留原稿，避免为了检查而反复润色。
把所有必交文件放在同一份检查清单里，交付时沿用这份清单，减少只查一部分、交另一部分的遗漏。
这是可安装使用的已知限制版，严格内容验收尚未全通过；用户接受的限制和其他一般未解决项分别列在验证说明中。它保留使用者原有配置，不带个人记忆，安装提问最多5个；简单任务保持轻量。

只包含一个技能。保留本地材料读取、任务覆盖、原件保护、错误记录与恢复功能，并加强最终内容的自主查错和修正。

修正经验已沉淀到 references/local-review.md、content_check.py 及可选项目检查 content_gate.py：分别命名容易混淆的事实、逐条核对影响结论的断言、发现错误后同步全部关联表述。项目检查需要单独启用，只约束已登记文件的最后回执，不证明语义正确，也不保证宿主隐藏纠正前文字。

安装见 docs/INSTALL.md；验证范围见 docs/VERIFICATION.md。源码准备：python3 tools/prepare_setup.py --output 指向仓库外尚不存在的新目录。
