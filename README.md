# WorkBuddy Quality Kit 5.2

让 WorkBuddy 根据材料安排 PPT 的重点。有模板时先找用途相同的原页，沿用标题位置、图文比例和强调方式。并列的实物同等展示，成果数字带上对象与比较基准，分支和先后在放映画面上能辨认。制作后回看实际投影片，针对遮挡、断行和缺少证据的结论作局部修正。

本包只有一个技能，同时包含既有的本地材料读取、文件保真、任务续接和内容复核工具。安装默认保留已有配置和同名技能。适合 WorkBuddy 读取自配置，也可以在单次任务中直接读取本目录的 SKILL.md。额外的演示技能按需选用。

将完整 ZIP 解压到新目录，或直接把 ZIP 交给 WorkBuddy。安装说明和可复制提示词在 [安装手册](docs/INSTALL.md)，安装后的检查方法见 [验证说明](docs/VERIFICATION.md)。采用 MIT 许可证。
